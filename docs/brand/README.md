# Viewrule logo

[viewrule-logo.png](viewrule-logo.png) is the horizontal project logo: a forest-green
V assembled from aligned rules, paired with the Viewrule wordmark. The mark connects
the project's name with its focus on alignment and comparable information.

The PNG is 2172 × 724 pixels with an opaque warm-white background. The README displays
it at 420 × 140 pixels so the wordmark remains readable in either GitHub theme. Keep
the 3:1 aspect ratio and the supplied clear space; do not stretch the artwork. This is
a raster asset; an editable vector source is not included.

## Provenance

Created with OpenAI image generation for this project, followed by an edit to make
the background opaque. The artwork is covered by the repository's [MIT license](../../LICENSE).

The generation brief requested a compact geometric V built from aligned horizontal
rules, a clear humanist sans-serif Viewrule wordmark, forest-green ink, and a 3:1
horizontal composition. It excluded taglines, mockups, gradients, and decorative
symbols. The final edit prompt was:

> Edit this Viewrule logo into a finished opaque README banner. Preserve the existing
> geometric forest-green V mark, the exact wordmark Viewrule, typography, spacing,
> proportions, and horizontal composition. The ONLY change is the background: place
> the existing artwork on a completely opaque, solid warm-white rectangular background,
> approximately #FAFAF5. This is an opaque banner, not a transparent logo export. Every
> pixel of the rectangular canvas must have full opacity, including the corners and
> the spaces within the letters and mark. Keep the approximately 3:1 landscape aspect
> ratio and current clear space. No checkerboard, texture, gradient, shadow, border,
> mockup, added text, or other design changes.
