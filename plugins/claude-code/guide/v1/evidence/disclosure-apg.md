# W3C APG: disclosure pattern

**Type:** standard. **Reviewed:** 2026-09-13.

## Source

W3C WAI. ARIA Authoring Practices Guide: Disclosure (Show/Hide) Pattern.

[Original / authoritative source](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)

## Scope

Keyboard interaction and WAI-ARIA roles, states, and properties.

## Limitations

Informative accessibility implementation guidance: a button, Enter/Space activation, and expanded state; aria-controls can identify the controlled section. This pattern is not a normative WCAG conformance test and does not establish cognitive benefits.
