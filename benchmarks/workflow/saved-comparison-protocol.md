# Saved comparison: Parcel desk

This is a deterministic application repair and report calibration, not an agent
efficacy experiment. Acceptance criteria are recorded before the repair/captures.
The complete existing Parcel desk application supplies fictional data, three
carrier charts, twelve shipments, filters, selection, disclosures, tabs, and quotes.

## Fixed task and expectations

An operator must compare carrier performance and investigate a shipment without
oversized framing pushing the working queue out of reach. At 1440×1000 and
1920×1080 CSS px, restore the existing reference composition under one unchanged
contract. A 390×844 capture also records the responsive result; desktop-only
relationship checks must not demand a horizontal arrangement on mobile.

- Heading height at desktop: at most 112 CSS px.
- Three carrier headings: top-anchor residual at most 2 CSS px.
- Three chart panels in one desktop row: gap coefficient of variation at most .05.
- Equal-priority chart panels: area coefficient of variation at most .05.
- Keep the shared units, period, population, source, all twelve shipment identities,
  three carrier identities, chart samples/domains, and readable 14px supporting type.
- Preserve search/clear, attention filtering, parcel selection, keyboard disclosure,
  tab changes, and URL restoration. These application assertions supplement the
  executable layout rules; a layout pass does not prove the interactions.
- Preserve both raw reports, original PNG bytes, capture-region geometry, the
  unchanged contract, authored commentary, and generated comparison with hashes.

The deliberate before presentation inflates the heading and rows, offsets the
middle chart heading, and allocates unequal chart widths/gaps. The repair removes
only that presentation override. No source data or thresholds change. The native
mobile reflow remains independent of desktop peer relationships.

## Report acceptance

Match page, checkpoint, and viewport dimensions; display both captures at equal
scale even when document heights differ. Numbered overlays come from explicitly
declared DOM regions recorded during capture, never inferred from old pixels.
Show measured sizes and scoped composition observations separately from authored
interpretation. Missing regions, missing images, changed contracts, changed browser
or capture settings, and reused evidence older than the before run must be explicit.
Comparison is evidence navigation, not an approval, beauty score, or verification
of an unchanged backend. The command must leave source runs and latest state intact.

Task relevance, overall hierarchy, acceptable whitespace, and whether this is a
useful real-world operations workflow remain human judgments. No symmetry rule is
introduced. This synthetic case cannot establish prevention effectiveness.
