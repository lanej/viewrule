# Text legibility: Parcel desk application exercise

This extends the installed workflow with an application change under one fixed
contract. It is a deterministic demo exercise, not a production field trial or
an agent efficacy experiment. The separate capacity trial and its evidence stay
unchanged; its two observed mobile defects supply new calibration fixtures.

## Task and expectations

Make the queue's status filter and sorting criterion persistently identifiable
with visible captions. Existing Parcel desk controls already fit their selected
labels. Adding captions must retain that space and preserve the shipment workflow.

- Capture first and final source at 390×844 CSS px, with destination sorting selected.
- Keep both native filter labels within a 1 CSS px intrinsic-width deficit.
- Keep the queue heading and result-count text fragments separate within 1 CSS px.
- Preserve all twelve shipment identities, carrier data, and native control values.
- Exercise status filtering, sorting, clearing, selection, keyboard disclosure,
  events tabs, and URL restoration; geometry alone cannot establish behavior.
- Save both complete source trees, original reports and native-scale PNGs, the
  unchanged rule/configuration contract, and an annotated saved comparison.

The first state reproduces the former visually hidden captions using the same
accessible text. The final state shows them; the layout aligns controls at their
bottom edges and permits wrapping. No defect is invented in the first state.
Both states should pass the new text contracts. The separate reduced regression
must fail the colliding-label and narrow-select cases, pass their repairs and a
wrapped alternative, and retain unsupported clipping/custom paint as unassessed.

Review the generated evidence at native scale. An increased toolbar height is the
cost of visible context, not a density regression by itself. Whether these captions
improve an operator's decisions remains human judgment. Do not infer time, cost,
or defect-prevention improvement from this exercise.
